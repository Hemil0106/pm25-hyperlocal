================================================================================
  1. PROJECT OVERVIEW
================================================================================

PM2.5 Hyperlocal Mapping is a full-stack geospatial intelligence platform
that generates 500m-resolution PM2.5 air quality maps for Indian cities by
fusing satellite imagery, ground station observations, meteorological data,
and topographic features using machine learning.

The system consists of:
  - A Python data pipeline (M1-M11) that ingests, QC's, and aligns data
  - A global data acquisition framework (M16) for scalable data engineering
  - A global training dataset builder (M17) with spatial validation
  - A FastAPI backend serving pre-computed outputs via REST
  - A React/TypeScript dashboard with MapLibre GL interactive maps

Currently supports 3 cities: Delhi, Pune, Mumbai
Target resolution: 500m PM2.5 prediction grids
ML model: XGBoost (Delhi prototype_local scope)

================================================================================
  2. PROBLEM STATEMENT & GOALS
================================================================================

PROBLEM:
  CPCB ground monitors are sparse (only ~4 stations per city). Satellite
  aerosol products are coarse (~1km). There is no practical way to see
  hyperlocal (500m) PM2.5 variation across a city in real time.

GOALS:
  1. Fuse multi-source data (satellite, ground, weather, GIS) into 500m grids
  2. Train ML models (XGBoost + Random Forest) for PM2.5 prediction
  3. Generate AQI sub-indices and pollution hotspot detection
  4. Serve outputs through a professional interactive GIS dashboard
  5. Build a scalable architecture supporting multi-city expansion
  6. Maintain scientific honesty throughout (no fabricated data/metrics)

APPROACH:
  7-step pipeline: Data Ingestion -> QC -> Feature Engineering -> ML Training
  -> Downscaling -> AQI+Hotspots -> Serving

scripts/generate_synthetic_aod.py (69 lines):
  Generates synthetic AOD rasters for all cities by reading existing
  PM2.5 rasters and producing correlated AOD GeoTIFFs.
  Formula: AOD = 0.08 + 0.018 * ln(1 + PM2.5) + spatial noise
  Range: 0.01 - 2.0 (physically realistic)
  Usage: python scripts/generate_synthetic_aod.py

scripts/fetch_real_aod.py (315 lines):
  Fetches real NASA MAIAC AOD (MCD19A2 V061) via Harmony API.
  Authenticates with Earthdata credentials, subsets by bbox/date,
  reprojects to UTM matching existing PM2.5 grids.
  Returns GeoTIFF directly (no HDF4 conversion).
  Requires: EARTHDATA_USERNAME, EARTHDATA_PASSWORD

   of the 1km parent model, not independent high-res prediction.
